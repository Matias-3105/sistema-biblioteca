# Sistema de Biblioteca

Programa de consola en Python que simula una biblioteca.

## Funciones
- Agregar libros
- Prestar libros
- Devolver libros

## Conceptos aplicados
- Programación orientada a objetos (clases Libro y Biblioteca)
- Composición
- Validación de entradas con try/except

## Cómo ejecutarlo
python biblioteca.py
